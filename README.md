# Make Sweet Moments

A static, responsive family website foundation for family memories, trips, polls, quizzes, calls, calendar events, and consent-based location sharing.

## Run locally

Open `index.html` in a browser, or run `python -m http.server 8000` and visit `http://localhost:8000`.

## Firebase integration

The current version is a frontend prototype using in-memory browser data. Connect Firebase Auth, Firestore, Storage, Cloud Messaging, and App Check before production use. Location sharing and calls should remain consent-based.
